- REA: Network content is retained only when selected; Playwright response-body bytes are API results and are not guaranteed to match wire bytes.
- REA: Request bytes are limited to what Playwright exposes; not_exposed does not establish body absence or multipart file coverage.
- REA: Captured response-body bytes are the result of Playwright's Response.body() API. Playwright may satisfy that API with a credentialed follow-up load of the request URL when CDP has no body, so transaction and event links do not verify that retained bytes came from the original network transaction.
- REA: Playwright scenario events do not expose request initiator stacks; receipt order does not prove causality.
- Some documented endpoints are disallowed by robots.txt for crawlers and were verified only because --robots-exempt was given. Check the provider's API terms; keep request volume low and cache aggressively.
- Undocumented endpoints are internal implementation details: they may change without notice and their reuse may be restricted by the site's terms of use. Check the terms before depending on them.
- Only GET/HEAD requests were replayed. Write operations are never executed automatically.
